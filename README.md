# ignisforge-assets

Claude Code-plugins.

## werkbank

Eén plugin met zes mods: tool-teller, bestandsboom, diff-paneel, veiligheidsbewaker, agent-tijdlijn en statusbalk. Zie [plugins/werkbank/README.md](plugins/werkbank/README.md).

Installeren, in Claude Code:

```
/plugin install werkbank --marketplace roel111/ignisforge-assets
```
